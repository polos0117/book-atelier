# book-atelier

**도서관에서 깨어난 책들이, 자신의 이야기를 세상에 남기기 위해 싸운다.**

책 자체를 인격으로 만든 수집형 카드 게임. 한 책은 하나의 전투 원리를 가지며, 세 폼(발단·전개·결말)은
그 원리를 이야기의 단계에 따라 다르게 쓴다. 개방은 그 폼의 명장면, 개정판은 외형 변형이다.

- 기획: [docs/GAME_CONCEPT.md](docs/GAME_CONCEPT.md)
- 책 설계표: [data/book-design.json](data/book-design.json) — `python3 tools/book-design.py check`
- 작업 지침: [AGENTS.md](AGENTS.md)
- 그림은 이 저장소에 두지 않는다 — [book-atelier-img](https://github.com/polos0117/book-atelier-img)

엔진(폼 결투·도감·생성기)은 pkm-atelier 에서 가져올 예정이다. 비상업 프로젝트다.
