# 어디서 무엇을 가져왔나 (2026-10-15)

책의 공방의 화면은 pkm-atelier 를 바탕으로 했다 — 한 캐릭터가 폼 셋 + 폼별 개방 셋을 갈아 입는 꼴이
책(발단·전개·결말 + 명장면)과 같기 때문이다. 그 위에 myth-atelier 와 atelier(건담)에만 있던 것을 얹었다.

## 공통 뼈대 — pkm

| 파일 | 무엇 | 바꾼 것 |

| `lib/workspace-ui.js` | 머리·항해·⚙ 설정·머리 접기·테마 고르개 | 문양을 책 모양 여덟으로. 화면 차례는 `PAGES` 한 곳 |

## 그림 — pkm (+ myth 의 썸네일 다시 만들기)

- `lib/img.js` — 주소·썸네일·`byStyle → byForm → {f, action}`·`casual`·`extra`·저장소 여럿(`where`). 그림 저장소는 `book-atelier-img` 하나.
  진열(myth 의 신전)을 더했다 — 서고(테마)마다 열둘, `book_hall_v1`.
- `tools/register-images.py` · `tools/roster.py` — 파일 이름이 곧 등록 정보. 책 열쇠는 설계표, 폼은 `vocab.form_key`, 개방은 `<폼>_open`.
- `tools/make-thumbs.py` — myth 것(`--redo` 로 덮어쓴 원본도 다시 만든다).
- 워크플로 — 코드 저장소 `register-images.yml`(myth 꼴), 그림 저장소 `thumbs.yml`(myth 꼴 + pkm 의 900 MB 경고).

## 서가 — pkm 도감 + myth + 건담

- pkm: 거르기(화풍·컷·폼)·검색·작게 보기·목록 자리 되돌리기·나란히 보기(위 폼 셋 · 아래 개방 셋)·큰 그림 넘기기
  (화살표·방향키·밀기, 끝을 넘으면 앞·다음 책)·책 넘기기 줄·휴대폰 뒤로 가기(기록 한 칸)·연출컷·일상컷 갤러리.
- myth: 화풍 비교 띠, 크게 보기(전체 화면·Esc·넘기기·원본 열기), `?book=` 바로가기, 진열과 서재 진열대(3D 회전 — 책장·마루·금 고리).
- 건담: 작업 현황 거르기("그림 없음"·"빈 자리 있음"), 그림 자리 진척(목록 머리), 조건 수가 붙은 초기화 단추, 생성기로 가는 길.
- 책 몫: 한 줄 인격·질문 → 갈등 → 답·고유 규칙(원리·대응)·세 폼(모습·역할·규칙 쓰임·명장면)·책 정보·설계(실루엣 6·얼굴 5), 시범 자리 표시.

## 생성기 — pkm + 건담 + myth

- pkm: 표(`lib/prompt-spec.js`)·조립(`lib/prompt-book.js`, pkm 의 prompt-anthro + prompt-lifestyle)·장면 무작위(`lib/prompt-random.js`)·
  체형/머리 그림 고르기(`lib/figures.js`)·화면(`lib/prompt-ui.js`). 외형 선택지 잠금·무작위·직접 입력·색 팔레트, 얼굴 설계 켜고 끄기,
  장면 값마다 랜덤·잠금(예시를 잠그면 갈래도), 일상컷 갈래·예시·세 축, 등록 그림 보기, 복사(안 되면 글을 골라 둔다), 책마다 저장.
- 건담: 되돌리기·다시 하기, 직전 책 외형 가져오기, 기록 내보내기(JSON), 책 고르개의 ✓·◐·· 표시, 올릴 파일 이름.
- myth: 일상컷 번호(1~9), 화풍 판 고르기(`data/style.json` 의 versions)와 참고 그림 자리.
- 책 몫: 설계표 줄(BOOK·SUBJECT·MATERIAL·SILHOUETTE·FACE·FORM)·개방은 명장면 문장·처음 연 책은 시범 폼에서·화풍 문장은 `data/style.json` 그대로.

## 일부러 뺀 것

- pkm 의 포켓몬 전용: 원작 외형 자료(Bulbapedia)와 입는 법(WEAR)·머리 특징 표현·타입 기운·장갑 폼 문장·종별 얼굴 설계(→ 책 설계표의 얼굴 5 묶음).
- pkm 일상컷의 포켓몬 세계 갈래: 직업(기본·섹시)·파트너 돌봄·나무열매. 축제·취미의 포켓몬 예시는 책 쪽으로 다시 썼다. 대신 "서고의 일상" 갈래.
- pkm 연출의 무장 고르기(책은 빈손), 화풍 견본 그림(→ 화풍 판의 참고 그림 자리).
- 건담의 콜라주·성별 둘·"이 값으로 뽑은 그림"(그림마다 설정 기록이 쌓이면 되살린다)·기록 폴더(`generation/`) — 기록은 그림 저장소 `records/` 로.
- myth 의 스킨·각성·저주, 박물관(3D 걷기).
- 놀이(폼 결투·진화 결투 등)는 아직 — 책 수·고유 규칙 코드가 정해지면 pkm 의 `lib/gwent.js` 를 옮긴다.
